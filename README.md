# random-password-generator-
don't want to risk using a password generator website, or app. This program is for you!! this is an open source python program that creates and saves your secure password on your PC, no WIFI needed 
all you need to do is install python and run the program, and a text file named passwords.txt will be saved to the same folder as the program
